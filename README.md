# Smart-_Parking_system
Smart Parking System using ESP8266, IR sensors, servo motor, and LCD display. IR sensors detect vehicle presence in each slot and update availability in real time. If a slot is vacant, the servo motor opens the gate; if full, entry is restricted. The system automates parking management efficiently and reduces congestion.

Additionally, the system enhances user convenience by providing instant feedback on parking availability, minimizing time spent searching for slots. It can be further extended with IoT connectivity to enable remote monitoring, data analytics, and smart city integration.
